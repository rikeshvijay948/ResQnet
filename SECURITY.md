The ResQNet team takes the security of this emergency platform and its users' personal safety data very seriously.

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

---

## 🛡️ Reporting a Vulnerability

If you discover a security vulnerability within ResQNet:

1. **Do not disclose the issue publicly** on GitHub issues, pull requests, or forums.
2. Please report security concerns privately to the project maintainers via email at:
   - `rikeshvijay948@gmail.com`
3. Include detailed steps to reproduce the vulnerability, including sample payloads or network traces.
4. The team will acknowledge receipt of your vulnerability report within 48 hours and work with you to coordinate a responsible resolution.
