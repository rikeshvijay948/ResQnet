# ResQNet – AI-Powered Emergency & Disaster Response Platform

## 📌 Overview

ResQNet is a full-stack web application designed to improve emergency and disaster response by connecting citizens, volunteers, NGOs, and government authorities on a single platform.

The platform enables users to report emergencies, coordinate rescue operations, manage relief resources, and monitor incidents through a centralized dashboard.

---

## 🎯 Problem Statement

During emergencies, information is often scattered across phone calls, messaging apps, and social media, leading to delayed response times and inefficient resource allocation.

ResQNet provides a unified platform to improve communication, coordination, and decision-making.
